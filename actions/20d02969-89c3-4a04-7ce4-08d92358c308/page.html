网址绑定

在已打开的浏览器标签中按预设规则一键切换；没有匹配标签时才打开新网址。适合多标签、多虚拟桌面工作流，避免同一站点反复新开页面。

主要功能

  • 复用已开标签：优先激活匹配的标签，而不是重复打开
  • 模糊匹配：标题与 URL 均支持片段匹配，可只写域名片段（如 youtube）
  • 顺序切换：多条命中时按绑定顺序自动轮换，无需再点选列表
  • 可视化设置：标题 / 网址分列编辑，拖动排序，非阻塞设置窗
  • 快捷录入：右键「添加当前网址」或设置窗「获取当前网址」

使用说明

  1. 安装 Quicker Connector 浏览器扩展并保持启用
  2. 在 Quicker 面板运行本动作；首次使用若列表为空，会自动添加当前浏览器标签为绑定项
  3. 再次运行：在已打开标签中匹配并切换；无匹配则打开列表第一项 URL
  4. 需要维护列表时，在动作上右键 → 设置绑定，编辑后点击保存
  5. 临时追加当前页：右键 → 添加当前网址

可将动作设为快捷键或手势，在工作区标签之间快速跳转。

切换规则

  • 当前标签不在匹配列表 → 跳到第一个匹配标签
  • 当前标签已在匹配列表 → 切到下一个（按绑定顺序循环）
  • 仅一条匹配且已在该标签 → 尝试下一条绑定，或打开其 URL
  • 完全无匹配 → 打开绑定列表第一项的网址

绑定格式

每条绑定格式为 标题|网址，例如：

  • 工作笔记|https://github.com/QuickerHub/quicker-workspace
  • youtube|https://www.youtube.com

不写竖线时整行视为 URL；保存时标题中的竖线会自动去除。列表顺序即切换优先级，可在设置窗拖动调整。

环境要求

  • Windows 10 及以上
  • .NET Framework 4.7.2 或更高
  • Quicker 1.45.0 及以上
  • Quicker Connector 浏览器扩展（Chrome / Edge 等 Chromium 系）

常见问题

  • 无法获取标签：检查扩展是否安装、是否允许访问当前浏览器
  • 匹配不到页面：尝试缩短或调整 URL / 标题片段；SPA 站点 URL 会变，建议绑定域名或稳定前缀
  • 设置未生效：需在设置窗点击「保存」；直接关闭不会写入
