固定到所有桌面

将当前窗口固定到所有虚拟桌面，或取消固定；右键菜单还可移动窗口、切换相邻桌面、新建桌面。 纯 C# 调用 Windows 虚拟桌面 COM 接口，无需 VirtualDesktop11.exe。

快速上手

  1. 将目标窗口置于前台（或后续通过参数指定句柄）
  2. 单击动作：切换「固定 / 取消固定」
  3. 长按或右键动作：打开扩展菜单（移动窗口、切换桌面、新建桌面）

通知分两行：第一行操作结果，第二行窗口标题；无相邻桌面等边界情况会显示 Warning。

单击（默认）

  • 切换固定：前台窗口固定到所有虚拟桌面，或取消固定
  • 等价于 mode=toggle（默认）

右键菜单

  • 移动窗口到相邻桌面：左 / 右
  • 切换到相邻桌面：左 / 右
  • 新建虚拟桌面：创建并切换到新桌面

可选参数

参数 说明
handle 窗口句柄；0 或不填表示前台窗口
mode toggle（默认）、pin、unpin、 moveWindowLeft / moveWindowRight、 switchLeft / switchRight、 newDesktop

右键菜单项通过动作参数传入，例如 mode=moveWindowRight。

环境要求

  • Windows 10 / 11（虚拟桌面功能）
  • Quicker 1.39.0 及以上（低权限 C# 脚本）

常见问题

  • 首次运行较慢？
    低权限 C# 脚本首次编译需数秒，之后会快很多。
  • 提示无法获取窗口句柄？
    请确认有前台窗口，或通过 handle 传入有效句柄。
  • 与 VirtualDesktop11.exe 的关系？
    本动作内置同等 COM 调用，无需额外下载 exe；对标经典 PinWindow 体验。
