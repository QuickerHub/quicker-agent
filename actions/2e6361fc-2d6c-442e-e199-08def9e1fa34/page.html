超级菜单 Rust 版

把常用收藏、文件路径和窗口操作放到随手可开的菜单中。默认打开以收藏为主的菜单，并按设置显示窗口管理、浏览器书签等入口。

动作沿用「超级菜单 n10」名称，当前使用 Rust + GPUI 原生界面，与「剪贴板 n10」共用 ClipHost 程序、设置和数据。

安装与开始使用

  1. 将本动作添加到 Quicker 面板，点击运行。首次运行会下载并安装所需组件，请保持网络连接并等待完成。
  2. 在菜单中展开收藏目录，选择需要的内容。可为本动作绑定常用快捷键，方便随时唤起。
  3. 右键点击 Quicker 面板上的动作，选择「设置」，进入「超级菜单」调整显示内容、菜单位置和外观。

Windows 10 / 11；Quicker V1 / V2 使用各自的启动依赖。安装入口按 Windows 系统架构选择 x64 或 ARM64 宿主，GPUI 界面无需 WebView2，也无需为 ClipHost 单独安装 .NET 10 运行时。

菜单能做什么

  • 收藏菜单：按目录浏览常用内容，方便快速选取和重复使用；菜单内容来自自己的收藏。
  • 文件菜单：维护常用文件和目录列表，展开浏览文件夹；在资源管理器或支持的「打开 / 另存为」窗口中定位目录。文件菜单的路径列表在设置中单独维护。
  • 窗口菜单：查看和切换窗口，使用置顶、最小化、关闭等窗口操作。
  • 其它入口：可通过动作参数直接打开文本、浏览器书签或剪贴板菜单。

菜单显示在「设置 → 超级菜单」调整；ClipHost 自身的全局快捷键在「设置 → 触发」中修改。

用动作参数直接打开指定菜单

本动作不带参数时执行 menu favor。通过 Quicker 快捷键或其它动作调用时，可将下列命令作为运行参数传入：

打开内容动作参数
收藏菜单（默认）menu favor
文件菜单menu file
窗口菜单menu window
文本菜单menu text
浏览器书签菜单menu bookmarks
剪贴板菜单menu clipboard

更新与手动下载

当前公开动作已同步 Rust / GPUI 0.31.15。更新 Quicker 中的动作后，再次运行即可检查所需组件；升级继续沿用已选择的数据目录。已经使用 Rust 版「剪贴板 n10」时，两项动作会复用同一个 ClipHost。

日常使用优先由动作完成安装。需要独立运行或手动下载时，可在 ClipHost 发布页选择与 Windows 架构对应的便携 ZIP，完整解压后运行 cliphost-app.exe，保留同目录的 DLL 和资源。

收藏菜单为空时，先确认已添加收藏内容；窗口管理、书签等附加入口可在「超级菜单」设置中开启。首次下载失败时，确认网络可用后重新运行动作。
