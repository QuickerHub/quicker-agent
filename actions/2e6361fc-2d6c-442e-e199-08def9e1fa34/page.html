超级菜单 Rust 版

把常用收藏、文件路径和窗口操作放到随手可开的菜单中。默认记住上次离开的分类；首次运行或宿主重启后打开收藏。支持文件、窗口、书签、文本操作和剪贴板六类入口。

动作沿用「超级菜单 n10」名称，当前使用 Rust + GPUI 原生界面，与「剪贴板 n10」共用 ClipHost 程序、设置和数据。

安装与开始使用

  1. 将本动作添加到 Quicker 面板，点击运行。首次运行会下载并安装所需组件，请保持网络连接并等待完成。
  2. 在菜单中展开收藏目录，选择需要的内容；菜单上方的分类栏可切换窗口、文件、收藏、书签、文本和剪贴板，也可将鼠标移到分类栏内滚动切换；本次打开内切换分类或打开浏览栏时，分类栏保持位置。可为本动作绑定常用快捷键，方便随时唤起。
  3. 分类栏末端的齿轮可调整当前分类及通用设置，右键分类可直达对应设置；也可右键点击 Quicker 面板上的动作选择「设置」，进入统一主界面管理超级菜单、文件列表和文本操作。

Windows 10 / 11；Quicker V1 / V2 使用各自的启动依赖。本版安装入口统一使用 x64 宿主，GPUI 界面无需 WebView2，也无需为 ClipHost 单独安装 .NET 10 运行时。

菜单能做什么

  • 收藏菜单：按目录浏览常用内容，方便快速选取和重复使用；菜单内容来自自己的收藏。
  • 文件菜单：维护常用文件和目录列表，展开浏览文件夹；支持图片、静音视频及常见文本和代码的悬浮预览。在资源管理器或支持的「打开 / 另存为」窗口中可定位目录，文件菜单的路径列表在设置中单独维护。
  • 窗口菜单：单击窗口行切换窗口，悬停展开操作，右键查看并复制标题、句柄、类名、进程路径和位置；同时显示窗口状态与 PID，结束进程前会确认。窗口缩略图默认关闭。
  • 文本操作：搜索并按用途或常用筛选规则，用键盘选择执行；可用自己的样例查看处理结果，并在管理页分组、编辑或新建，保留已有规则。
  • 剪贴板菜单：列表和内容预览双栏显示，支持滚动加载、就地删除，以及文件右键操作和子目录展开。
  • 其它入口：可通过动作参数直接打开浏览器书签或指定分类。

菜单显示在「设置 → 超级菜单」调整；ClipHost 自身的全局快捷键在「设置 → 触发」中修改。打开或操作超级菜单时，贴边隐藏的剪贴板保持收起。

贴顶晾衣绳：从屏幕顶边浏览文件

在「设置 → 超级菜单 → 文件菜单」开启「贴顶晾衣绳」（默认关闭）。它与超级菜单的「文件」分类并存，共用自定义目录；前台为全屏程序时停用。

  • 展开与浏览：指针停留在所在屏幕顶边展开标签，悬停标签打开文件纸片，可在纸片内进入下一级或返回。离开或单击别处收起。
  • 固定纸片：点击夹子固定，绳子收起后仍可查看，最多固定 3 张；单击条目沿用文件菜单的定位、转到或打开规则，Ctrl + 单击保持展开。
  • 整理与拖放：拖动自定义标签排序，拖到取下区域移出列表，取下后 6 秒内可撤销；拖入已有文件夹可添加到绳上，纸片中的文件可复制拖出。取下标签不会删除实际文件或目录。
  • 键盘操作：指针位于绳子或纸片上时，用方向键浏览，Enter 执行、Ctrl + Enter 保持展开，空格固定或松开纸片，Esc 逐层返回或收起。选中自定义根标签时可用 Delete / Backspace 取下，撤销期限内按 Ctrl + Z 恢复。

用动作参数打开菜单或聚合搜索

本动作不带参数时执行 menu，与快捷键共用上次分类记忆；首次或宿主重启后打开收藏。通过 Quicker 快捷键或其它动作调用时，可将下列命令作为运行参数传入：

打开内容动作参数
记忆上次分类（默认）menu
指定打开收藏菜单menu favor
文件菜单menu file
窗口菜单menu window
文本菜单menu text
浏览器书签菜单menu bookmarks
剪贴板菜单menu clipboard
CeaBox 聚合搜索窗口search show

search show 打开独立搜索窗口，按关键词或拼音查找收藏、剪贴板历史和已安装的 Quicker 动作。动作搜索需要 Quicker 连接。

更新与手动下载

本动作使用 Rust / GPUI ClipHost。更新 Quicker 中的动作后，再次运行即可检查所需组件；本版继续沿用已选择的数据目录和原有存储格式，不自动转换为新格式或移动用户数据。已经使用 Rust 版「剪贴板 n10」时，两项动作会复用同一个 ClipHost。

日常使用优先由动作完成安装。需要独立运行或手动下载时，可在 ClipHost 发布页下载 Windows x64 便携 ZIP，完整解压后运行 cliphost-app.exe，保留同目录的 DLL 和资源。

在统一主界面的「关于与更新」可手动检查新版；程序启动后和运行期间每两小时也会自动检查，自动检查不下载、不安装。点击「更新并重启」后才下载并校验升级。旧版首次升到 0.32.0 仍通过 Quicker 动作或便携包完成。

本次宿主为 0.32.6.0，Quicker V1/V2 入口为 0.31.27.1。查看 0.32.6 更新说明。

收藏菜单为空时，先确认已添加收藏内容；窗口管理、书签等附加入口可在「超级菜单」设置中开启。首次下载失败时，确认网络可用后重新运行动作。
