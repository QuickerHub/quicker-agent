翻译小窗

打开 OcrStudio 独立翻译小窗，支持手动输入、截图 OCR 翻译与剪贴板翻译；从 Quicker 触发时的默认行为可在小窗设置中切换。

主要功能

  • 独立翻译窗口：不进入 OCR 工作台，专注翻译与输入
  • 多种输入方式：手动输入、框选截图 OCR 后翻译、剪贴板内容翻译
  • 可配置触发：从 Quicker 动作触发时，默认只打开小窗、立即截图翻译或立即剪贴板翻译
  • 多翻译服务：与 OCR 工作台共用翻译引擎与语言设置

使用说明

  1. 安装本动作及依赖的 OCR 工作台 动作（含 OcrStudio 依赖包）
  2. 触发「翻译小窗」动作，默认只打开翻译小窗
  3. 在小窗右上角设置中调整「从 Quicker 触发时」：只开小窗 / 截图翻译 / 剪贴板翻译
  4. 也可使用专用动作传参：translate capture（截图）、translate clipboard（剪贴板），会覆盖上述默认设置

应用内打开的翻译小窗不受「从 Quicker 触发时」设置影响。

环境要求

  • Windows 10 及以上
  • .NET Framework 4.7.2 或更高
  • Quicker 1.45.0 及以上
  • 已安装并配置 OcrStudio 依赖（通过 OCR 工作台动作自动下载）
