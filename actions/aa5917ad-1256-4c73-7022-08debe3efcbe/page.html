QuickerAgent

QuickerAgent 是面向 Quicker 的桌面 AI 助手：用对话帮你搜索与运行动作、编写与修改动作、整理子程序与自动化任务。安装包内已集成运行时，开箱即用。将本动作安装到面板后运行一次（建议加入自动运行），即可启动 RPC 服务；若本机尚未安装 QuickerAgent，运行时会自动提示下载与安装。

主要能力

  • 对话式操作：用自然语言描述需求，由 Agent 调用 Quicker 能力完成任务
  • 动作编写：创建、修改动作步骤与变量，减少在设计器里反复点选
  • 多轮对话：标题栏多标签、历史侧栏，按工作目录区分上下文
  • 模型配置：在应用内设置 LLM 提供商与模型；发布版可内置可用模型（无需自行填写 Key）
  • 桌面体验：Electron 原生窗口、自定义标题栏、深浅色主题

版本与变更见本页「最近更新」；无法打开 GitHub 时请用下方 Bitiful 直链获取安装包。

安装与连接

  1. 将本动作安装到 Quicker 面板，点一次运行（或加入自动运行），以启动本机 RPC 并完成与 Quicker 的连接。无需在 Quicker 里单独安装其它依赖库。
  2. 按运行时的提示安装或更新 QuickerAgent（已安装时会提示新版本，可点击通知下载）。
  3. 从开始菜单或桌面快捷方式打开 QuickerAgent；首次使用可在设置中确认与 Quicker 的连接状态。
打开「自动运行」设置

快速开始

  1. 确认 Quicker 已启动，并已运行过一次本动作
  2. 按提示完成 QuickerAgent 安装后，打开应用
  3. 在设置中确认已连接 Quicker，并按需选择 LLM 模型
  4. 在输入框描述你想做的事（例如「列出带剪贴板关键字的动作」或「新建一个复制文本的动作」）

使用建议

  • 为当前任务设置工作目录，便于 Agent 读写该目录下的文件
  • 复杂编辑可分多轮对话完成；侧栏可收起，主区域留给对话与工具结果
  • 若连接断开，先在 Quicker 中再运行一次本动作，再在 QuickerAgent 设置里重新检测

环境要求

  • Windows 10 及以上
  • 较新版本的 Quicker
  • 本动作在面板中至少运行过一次，QuickerAgent 才能稳定连接

常见问题

  • QuickerAgent 显示未连接 Quicker？
    确认 Quicker 已启动，在面板里再运行一次本动作；必要时重启 QuickerAgent 后在设置中重新检测。
  • 尚未安装 QuickerAgent / 需要升级？
    在 Quicker 中再运行一次本动作，按弹窗提示下载；也可从下方「参考」用 Bitiful 直链手动下载（无需 GitHub）。
  • 无法调用模型？
    在 QuickerAgent 设置中检查 LLM 配置；若使用需自备 Key 的模型，请填写有效的 API Key。
  • 升级后行为异常？
    再运行本动作获取最新版下载链接，或从「参考」Bitiful / GitHub 手动覆盖安装，并确保本动作也已更新到最新分享版本。
