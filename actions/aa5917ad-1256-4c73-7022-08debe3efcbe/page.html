QuickerRpc

在命令行里调用 Quicker 能力。安装 qkrpc 与本动作后，可在终端创建/无头编辑动作与公共子程序、在动作中调用子程序、运行动作、更新分享动作等，适合脚本、自动化与 AI Agent 场景。

主要能力

  • 无头 CLI：qkrpc help --json 自描述；--json 结构化输出，适合 Agent
  • 动作：创建、按场景搜索、读取/patch/replace、运行、分享更新等（action *）
  • 公共子程序：创建、搜索、无头编辑；callIdentifier 供动作内 sys:subprogram 步骤调用（subprogram *）
  • 步骤目录：step-runner search/get，写 patch 前查参数键名
  • 内置指南：guide get --topic authoring-workflow、subprogram-workflow 等（随 CLI 更新）

版本与变更见本页「最近更新」或 GitHub Releases。

安装

1. 安装命令行工具（始终安装 最新 版 qkrpc）：

$p="$env:TEMP\qkrpc-install.ps1"; iwr https://github.com/QuickerHub/quicker-rpc/releases/latest/download/install.ps1 -OutFile $p -UseBasicParsing; & $p

安装到 %LOCALAPPDATA%\Programs\qkrpc 并写入 PATH。完成后请新开终端。

2. 安装本动作并手动运行一次

在 Quicker 面板安装后手动运行一次，启动 RPC（管道 QuickerRpc_Server_QRPC2026）。

ping 失败时先手动运行本动作；CLI 可 quicker:runaction 自动拉起（--no-bootstrap 跳过）。

3. 更新插件依赖

在 Quicker 设置 → 扩展 → 依赖库 中将 quicker.rpc 更新到最新（与当前 qkrpc 大版本匹配；见 Release 说明）。

快速开始

qkrpc ping --json
qkrpc help --json
qkrpc guide get --topic authoring-workflow --json
qkrpc guide get --topic subprogram-workflow --json

完整命令表以 help --json 为准；人类可读摘要见仓库 docs/cli-commands.md。退出码 0 成功。

命令概览

下列为稳定能力分组；具体子命令以 qkrpc help --json 为准。

连接与指南

命令说明
ping检测 RPC 是否在线
help --json机器可读 CLI 参考（推荐 Agent 首选）
guide get --topic <id>内置文档（如 authoring-workflow、subprogram-workflow）

动作（无头编辑）

命令说明
action create无头创建 XAction（可选 @qkrpc 虚拟页）
action list/search [--scope …]列出或搜索本地动作
action get / patch / replace读取、局部 patch、整体替换
step-runner search/get步骤目录；patch 前必查参数键名
action run / edit / update / delete运行、设计器、分享更新、删除

公共子程序

命令说明
subprogram search / list搜索或列出；含 callIdentifier
subprogram create无头新建
subprogram get / patch / replace读取、patch、整体替换
subprogram edit / edit-var / delete设计器、变量默认值、删除

Agent 写动作

流程与约束以 CLI 内置指南为准（会随版本更新）：

qkrpc guide get --topic authoring-workflow --json

典型步骤：action create 或 action list/search → action get → step-runner get → action patch。

在动作中调用公共子程序

qkrpc guide get --topic subprogram-workflow --json

要点：subprogram search/get 取得 callIdentifier → step-runner get --key sys:subprogram 确认参数键 subProgram → action patch 添加步骤。勿猜标识符或键名。

常用示例

qkrpc action create --title "我的动作" --json
qkrpc action search --scope chrome --query "复制" --json
qkrpc subprogram search --query "json" --json
qkrpc action run --id "我的动作" --wait --json

环境要求

  • Windows 10 及以上
  • 较新版本的 Quicker（建议保持软件与依赖库为最新）
  • 本动作至少运行过一次，RPC 才会监听命名管道

常见问题

  • ping 失败？
    手动运行本动作；确认 Quicker 已启动，且 quicker.rpc 依赖已更新。
  • 终端找不到 qkrpc？
    安装后新开终端；或检查 %LOCALAPPDATA%\Programs\qkrpc。
  • 命令不存在或报错？
    重新执行安装脚本安装最新 CLI，并更新 Quicker 中 quicker.rpc 依赖。
  • 子程序调用无效？
    subProgram 须填 callIdentifier（来自 subprogram search/get），不要手写子程序名。
  • 步骤参数写不进去？
    必须先 step-runner get --key …，不要猜键名。
