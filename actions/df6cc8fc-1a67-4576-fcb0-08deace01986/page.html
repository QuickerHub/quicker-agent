剪贴板 n10

基于 IntelliTools / ClipHost 的 .NET 10 重构预览版。除完整剪贴板历史、收藏与超级面板外，新增便捷粘贴、复制成功提示、IM 富文本与全新 ClipHost 主窗口；支持 Quicker V1/V2 双宿主，持续优化无焦点键盘操作与全局快捷键。

当前版本重点（v0.30）

  • 便捷粘贴：按住 Alt+` 弹出最近记录预览，连按 ` 切换条目，松开 Alt 粘贴；支持滚轮/方向键导航、会话内 1/2 行操作、D 删除、选中项短时记忆、Esc 取消
  • 统一预览浮层：便捷粘贴列表与详情合并为单面板，靠近光标锚定，贴屏幕边缘时自动收敛
  • 复制成功 Toast：复制后按内容类型展示透明浮层预览，多显示器适配，不阻挡操作
  • IM 富文本：支持 QQ / 微信 / 企业微信等富文本剪贴板，列表可预览，编辑区所见即所得，图片可持久化
  • ClipHost 主窗口：首页、剪贴板、个性化、触发、帮助、数据管理统一侧栏；标题栏居中搜索设置项
  • 数据安全：清空剪贴板历史前确认，约 8 秒内可撤销，避免误删

便捷粘贴

无需打开完整剪贴板窗口，即可快速预览并粘贴最近记录（默认快捷键 Alt+`，可在设置中修改或禁用）。

  • 唤起与切换：按住 Alt 再按 ` 打开；保持 Alt 按住时连按 ` 在条目间切换
  • 导航（推荐滚轮）：全程按住 Alt 时，直接上下滚动鼠标滚轮即可切换选中项——向上选上一项、向下选下一项，到头自动循环，手不用离开鼠标最为顺手；也可用方向键 ↑/↓ 或连按 `。置顶条目以金色序号显示在列表末尾
  • 行内操作：Alt+1 / Alt+2 可武装「模拟输入」或「打开链接/路径」等操作，松开 Alt 执行
  • 删除：Alt+D 删除当前选中项（从剪贴板历史中移除，不粘贴）
  • 取消：Esc 关闭浮层且不粘贴（含 Alt+Esc，由 hook 拦截，避免误关前台窗口）
  • 配置：ClipHost 主窗口 设置 → 便捷粘贴（独立页）：全局快捷键、非置顶条数上限、Alt+1/2 行操作绑定、Alt+D 删除开关、记住上次选中项（默认 10 秒，0 为关闭）

右键动作按钮 →「连续粘贴」可进入连续粘贴模式（与便捷粘贴不同，适合批量插入）。

剪贴板面板

  • 类 Win+V 体验：唤出时尽量不抢占前台焦点；可开关「无焦点模式」（关闭后会激活并聚焦搜索框）
  • 全局唤起：默认 Ctrl+` 为点按切换显示/隐藏，按完即松开，不要按住 Ctrl 当引导键
  • 键盘导航：方向键移动选中，Enter 粘贴；Delete 删除当前项；按 F 聚焦搜索框
  • CapsLock 扩展热键（无焦点模式，与 Quicker 引导键同布局）：CapsLock+I/J/K/L 上下左右，O 退格搜索，Q 关闭
  • 极简列表：可选极简显示模式，图片预览高度可单独配置
  • 多选与合并：Ctrl / Shift 多选后可合并粘贴或批量操作（窗口有焦点时）
  • 图片与路径：本地图片路径、多文件中的图片文件可显示缩略预览；列表尺寸标签布局已优化
  • 内联链接：文本中的链接悬停可快速打开
  • 黑名单：可配置前台进程黑名单，指定应用复制时不收录

关于 Alt 与 Ctrl：便捷粘贴默认用 Alt+`，全程按住 Alt 切换/粘贴很自然。 剪贴板窗口的 Ctrl+` 只适合点按唤起；Ctrl 作引导键按字母（如 Ctrl+W）既别扭，也容易撞上编辑器/浏览器快捷键，无焦点模式下 ClipHost 也不会拦截这类组合。 若希望「按住引导键 + 字母」操作列表，请用 CapsLock 引导，或 Quicker 以 Alt 为引导键唤出动作后再操作。

收藏与扩展

  • 收藏夹：常用片段固定；支持文本、链接、路径、Quicker 动作等；可在窗口内直接编辑多类型条目
  • 捷径面板 n10：与剪贴板共用 ClipHost 本地服务，收藏结构同步，超级面板快速唤出
  • 超级菜单：ClipHost 首页可打开文件、窗口、文本、收藏、书签等超级菜单
  • 窗口位置：剪贴板与面板均可配置相对光标、屏幕中心等显示位置
  • 全局快捷键：剪贴板显示/隐藏、收藏面板、便捷粘贴、Win+V 风格唤起等可在设置中配置（留空即禁用）

收藏云同步功能暂时下架，恢复后将在 ClipHost 主窗口提供入口。

ClipHost 本地服务

  • 后台常驻：剪贴板监听、全局快捷键、便捷粘贴与 Toast 由 ClipHost 提供，Quicker 插件负责启动与桥接
  • 双宿主插件：同时提供 net472（Quicker V1）与 net10（Quicker V2）依赖包，按环境自动选用
  • 软件信息：帮助 / 文档页可查看 ClipHost、运行时与组件版本，便于排查问题
  • .NET 10 引导：未安装运行时时，面板内可打开安装引导并检测两项必需运行时
  • 独立安装包：除 Quicker 插件外，也可使用 ClipHost setup.exe 或便携 zip 独立部署

安装与要求

  • 最低 Quicker 版本：1.39.0，建议使用 1.45.0 及以上
  • Windows 10 及以上；建议与稳定版剪贴板二选一常驻，避免冲突
  • 安装后触发动作即可使用；开机自启请将本动作加入 Quicker「自动运行」
  • IntelliTools 优先直接启动配置路径或插件包内的 ClipHost，减少升级时的文件占用问题
打开「自动运行」设置

.NET 10 运行时（ClipHost 必需）

剪贴板后台服务 ClipHost 基于 .NET 10，且同时使用 WPF 与 ASP.NET Core。 请安装 Windows Desktop Runtime 10.x 与 ASP.NET Core Runtime 10.x 两项共享运行时； 仅安装其中之一时，进程仍可能无法启动。

与 IntelliTools 内「.NET 10 安装引导」一致；版本号随官方更新，下列直链以 10.0.8 为例，其它版本请在 .NET 10 官方下载页 选择对应架构。

手动下载（直链安装包）

运行时 Windows x64 Windows arm64
ASP.NET Core Runtime aspnetcore-runtime-10.0.8-win-x64.exe aspnetcore-runtime-10.0.8-win-arm64.exe
Windows Desktop Runtime windowsdesktop-runtime-10.0.8-win-x64.exe windowsdesktop-runtime-10.0.8-win-arm64.exe

命令行安装（winget）

在提升权限的命令提示符或 PowerShell 中执行（与 IntelliTools 自动安装相同）：

  • winget install Microsoft.DotNet.AspNetCore.10 --accept-package-agreements --accept-source-agreements
  • winget install Microsoft.DotNet.DesktopRuntime.10 --accept-package-agreements --accept-source-agreements

若 winget 不可用，请使用上表直链或官方下载页手动安装。

使用提示

  • 再次触发动作可关闭剪贴板面板（适合绑定快捷键）
  • 右键动作按钮可打开设置、连续粘贴、暂停/恢复监听、正常或强制退出 ClipHost
  • 文本指令除 vv + Tab 外，支持连按三次 v 打开剪贴板窗口
  • 遇到问题可先查看动作页「讨论」区，或到 QQ 群反馈
