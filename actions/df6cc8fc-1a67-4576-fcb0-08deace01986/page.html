剪贴板 Rust 版

记录复制过的文本、图片和文件，随时搜索、编辑、收藏并快速粘贴。 当前采用 Rust + GPUI 原生界面，由 ClipHost 提供独立后台服务，支持 Quicker V1 和 V2。

本动作沿用「剪贴板 n10」名称，当前安装和启动的是 Rust 版。

安装与开始使用

  1. 将本动作添加到 Quicker 面板，点击运行。首次使用会自动下载所需程序；更新后再次运行动作即可检查并更新依赖。
  2. 复制内容后，再次运行动作打开剪贴板窗口。点击记录即可粘贴，也可以搜索后选择需要的条目。
  3. 需要登录 Windows 后自动运行时，在程序设置中开启「开机启动」。
  • 系统要求：Windows 10 / 11，提供 x64 和 ARM64 便携包；动作安装入口按系统架构选择宿主。
  • Quicker：最低版本 1.39.0，支持 V1 / V2，动作按宿主自动选择启动依赖。
  • 界面运行环境：已切换为 GPUI 原生界面，不再依赖 WebView，无需安装 Microsoft Edge WebView2 Runtime。

Rust 版 ClipHost 无需单独安装 .NET 10 的 Desktop Runtime 或 ASP.NET Core Runtime。

剪贴板历史与收藏

  • 历史记录：保存文本、图片、文件及富文本内容，支持搜索、来源筛选和分类。
  • 临时图片：截图软件等已知临时位置的单个图片文件会保全到数据目录，便于源文件回收后继续使用；普通文件和多文件记录继续保留原引用。
  • 失效文件记录：仅在展示时检查。普通未置顶记录全部文件失效后，首次发现满 24 小时、再次展示并确认仍全部失效时才清理记录；收藏和外部文件保留。
  • 常用内容：将记录置顶或加入收藏，方便重复使用；文本内容可直接编辑。
  • 粘贴方式：富文本可选择「保留格式」或「仅文字」，图片与文件保留各自的剪贴板格式。
  • 窗口外观：可调整主题、列表显示和窗口位置；支持折叠、隐藏及贴边收起。

CeaBox 聚合搜索

运行本动作时传入 search show 参数，打开独立的聚合搜索窗口，一次查找收藏、剪贴板历史和已安装的 Quicker 动作；支持关键词、拼音与来源筛选。

搜索已安装动作需要 Quicker 连接；独立使用 ClipHost 时，仍可搜索本机历史与收藏。

便捷粘贴

不打开完整窗口，也能预览最近记录并快速回贴。快捷键和鼠标触发方式可在「便捷粘贴」设置中调整。

  • 键盘触发：按住 Alt 再按 ` 唤起；保持 Alt 按住时切换条目，松开后粘贴。
  • 鼠标侧键：按住配置的侧键并滚动滚轮，打开预览并切换记录，松开侧键后粘贴。
  • 取消：按 Esc 关闭预览，不执行粘贴。

侧键模式只接管「侧键 + 滚轮」组合，侧键单击和单独长按仍可用于浏览器后退、Quicker 轮盘等原有操作。

常用操作

  • 显示 / 隐藏：再次点击动作，或点按 Ctrl+` 切换剪贴板窗口；全局快捷键可在设置中修改。
  • 托盘：左键点击托盘图标打开剪贴板，右键打开菜单。
  • 动作右键菜单：可进入设置、连续粘贴、暂停 / 恢复监听和退出程序。
  • 连续粘贴：适合将多条记录依次插入，与便捷粘贴的快速选取用途不同。
  • 局域网互传：点击底栏互传按钮，在剪贴板右侧打开会话；点击左侧历史记录或将记录拖入右栏，即可发送给当前选中的已配对设备。输入区按 Enter 发送，按 Shift+Enter 换行。
  • Windows 设备同步：在「局域网 → 设备与连接」为已配对电脑单独开启文本、静态图片同步，并分别设置是否保存到历史、是否替换当前剪贴板。同步初始关闭；文件继续手动互传。

旧版数据与当前范围

程序优先沿用已设置的数据目录；尚未设置时，会检测可用的旧版 C# / WPF 数据目录并继续使用。原 Rust 数据目录保留，可在「管理 → 数据」查看或切换位置。

本版继续沿用原有存储格式，不会自动转换为新格式或移动用户数据。

切换旧版与 Rust 版时，先正常退出原有程序，再启动需要使用的版本。

当前公开版本以本地剪贴板和收藏为主，手机同步与云同步尚未开放。

独立使用与手动下载

ClipHost 可以独立运行。使用 Quicker 动作时优先让动作自动下载；独立使用时可在 ClipHost 发布页选择与 Windows 架构对应的 x64 或 ARM64 便携 ZIP， 解压完整目录后运行 cliphost-app.exe，保留同目录的运行库和资源。当前 Rust 发布提供便携包。

本次宿主为 0.31.24.0，Quicker V1/V2 入口为 0.31.24.1。查看 0.31.24 更新说明。
